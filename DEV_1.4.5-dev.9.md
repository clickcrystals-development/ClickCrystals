## Changes / Изменения

- GUI full-screen overlay now uses logical, GUI-scaled dimensions rather than physical framebuffer dimensions.
- Custom rectangle, rounded rectangle, textured rounded rectangle and stroked rounded rectangle render states use conservative outward-rounded bounds, reducing under-culling of fractional-size elements.
- Small per-version `GuiPixelBounds` helper and 10,006 deterministic and seeded property assertions.
- No change to original UI theme, CCS semantics, combat features, original authorship or MIT license.

## Validation gates / Проверки до создания черновика

- Build 1.21.11 with Java 21; build 26.1.2 and 26.2 with Java 25.
- Run existing isolated Java runtime regression suite for each target.
- Run GUI geometry regression suite for each target (10,006 checks).
- Build Fabric mod and validate ZIP integrity, version metadata, retained original author and artifacts.
- Ensure exactly three target JARs; write SHA256SUMS.txt.

**Evidence:** If the draft was generated by the workflow, these gates completed in CI. This does not mean Minecraft was launched in an actual GUI session. See the workflow run for logs and status.

## Known limitations / Ограничения

- In-game GUI screenshots, Minecraft client startup, 10-world gameplay tests, multiplayer PvP, FPS benchmarking, Android and inter-mod compatibility are not established by this workflow.
- This only addresses specific graphics bounds/overlay issues. It does not replace Minecraft's renderer, implement SDF/MSDF font rendering or guarantee FPS improvements.
- The earlier CCS runtime/AI/combat limitations of dev.8 still apply.
- Install one matching JAR only; back up all configs and scripts first. Avoid use on main profiles until tested.
